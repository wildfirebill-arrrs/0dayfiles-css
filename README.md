# 0DayFiles.net CSS Stylesheets (Unofficial)

200 CSS stylesheets for 0DayFiles.net — 100 external (theme overrides) + 100 standalone (self-contained). Unofficial, not associated with 0DayFiles.net. Use at your own risk.

## Usage
Paste the raw URL of a file into the site's custom CSS field (Profile -> General Settings -> Edit).

Raw URL format:
https://raw.githubusercontent.com/wildfirebill-arrrs/0dayfiles-css/main/external/001-neon-1.css
https://raw.githubusercontent.com/wildfirebill-arrrs/0dayfiles-css/main/standalone/001-magazine-1.css
